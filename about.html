neo-ukiyoe-view

A non-commercial creative project.

neo-ukiyoe-view is a personal, non-commercial project that discovers scenic landscapes from around the world, reimagines them in the traditional Japanese ukiyo-e woodblock-print style, and shares the resulting artwork on social media.

How we use the Pinterest API

We use the Pinterest API only to read aggregated trend data (e.g. trending travel and landscape keywords) to help decide which real-world scenery to feature next. We do not collect personal information, and we do not post, modify, or delete any content on Pinterest.

What we create

  • Selecting notable world landscapes as subjects
  • Transforming them into ukiyo-e–style artwork
  • Sharing the artwork on social platforms
